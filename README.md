# Cégep Gérald-Godin - Android Development Coursework

This repository contains practical laboratory assignments, exercises, and exam preparation projects completed during the mobile application development curriculum at Cégep Gérald-Godin.

## 📂 Repository Contents

* **Labo2 & Labo2_Partie2**: Practical lab exercises focusing on Android development workflows, UI layout structures, and event handling.
* **Exercice1**: Hands-on exercises reinforcing Kotlin programming concepts and Jetpack Compose component design.
* **RevisionExam**: Comprehensive review application combining core Android architecture, UI layouts, and lifecycle handling in preparation for course evaluations.

## 🛠️ Technologies Used
* **Language:** Kotlin
* **Framework:** Android SDK & Jetpack Compose
* **Tools:** Android Studio, Gradle (Kotlin DSL)
